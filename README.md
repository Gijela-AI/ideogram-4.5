# Try Ideogram 4.5

Online AI image generation and editing powered by the Ideogram 4.5 model. No local GPU, no subscription, pay per use.

Live: https://tryideogram45.com

## Features

- Text-to-image: prompt + aspect ratio + style presets
- Image-to-image: upload a reference photo to edit or create variants
- Local repaint: select a region and change only that area, background stays untouched
- Free tier: generate with watermark preview. Paid: full-resolution download ($9.9/1, $19.9/3, $29.9/5)
